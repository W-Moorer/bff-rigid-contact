# CMAME Data Deposit Package

This file records the data package that supports the manuscript
`Contact-Aligned Local Graphs for Smooth Rigid Frictional Contact on Coarse
Surface Meshes`. It is intended for deposition in a DOI-bearing repository such
as Zenodo, Mendeley Data, Figshare, OSF, or an institutional repository before
journal submission.

## Dataset title

Contact-Aligned Local Graphs validation data for smooth rigid frictional contact
on coarse surface meshes

- Current public development repository:

## Recommended deposit tiers

The generated manifest separates the archive into six practical tiers.

| Tier | Role |
|---|---|
| `core_result` | CSV/JSON/Markdown result artifacts needed to reproduce manuscript tables and curves |
| `reproduction_code` | Python/C++ source, scripts, and tests needed to regenerate the reported artifacts |
| `manuscript_and_metadata` | Manuscript source, compiled preview, highlights, audit notes, data README, and repository metadata |
| `manuscript_figure` | PNG/PDF/SVG figure exports used directly by the manuscript |
| `high_resolution_figure` | TIFF figure exports for journal production |
| `full_frame_vtk_animation` | High-time-resolution VTK frames for ParaView inspection; useful for visual validation but not required for reproducing tables |

The current manifest reports 15,714 files and 4.037 GiB total. The manuscript
tables and plotted curves are reproducible from the non-VTK tiers; the
`full_frame_vtk_animation` tier accounts for most of the package size and can be
uploaded as a separate archive part if the repository supports multi-file
records.
