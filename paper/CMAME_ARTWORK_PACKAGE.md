# CMAME Artwork Package

This file records the manuscript artwork prepared for submission to
`Computer Methods in Applied Mechanics and Engineering`.

## Artwork Policy Note

The manuscript figures are computational plots and model schematics generated by
the repository script `scripts/make_paper_story_figures.py` from analytic model
definitions and locked CSV/JSON result artifacts, except for the cam--roller
model schematics supplied as `paper/figures/models/CALG_Model_cam_1.png` and
`paper/figures/models/CALG_Model_cam_2.png`. No raster image-generation model
was used to create the submitted scientific figures.

All SVG and PDF exports preserve editable Times-family text where the backend
supports text objects. TIFF exports are supplied as high-resolution production
files, and PNG exports are retained for preview and local manuscript builds.

## Final Author Checks

- Confirm that figure numbering in the submission system matches the manuscript.
- Upload separate production files rather than extracting figures from the PDF.
- Use the PDF or SVG versions when editable vector artwork is preferred by the
  journal system; use TIFF files when raster production artwork is requested.
- Keep captions in `calg_cmame_draft.tex`, not embedded as external text files.
